Privacyverklaring

Padel Escape (Ruben Jansma) verwerkt persoonsgegevens die je via deze website invult. Deze privacyverklaring legt in het kort uit wat er met je gegevens gebeurt.

Welke gegevens?

Als je het contactformulier invult, verwerk ik: je naam, e-mailadres, eventueel telefoonnummer en het bericht dat je stuurt.

Waarvoor?

Uitsluitend om jouw aanvraag te beantwoorden en persoonlijk contact op te nemen over training, een padel trip, kidslessen of een clinic.

Hoe lang bewaard?

Zolang nodig om je aanvraag af te handelen. Als er geen boeking uit voortkomt: maximaal 12 maanden. Bij een boeking bewaar ik gegevens conform de wettelijke bewaartermijnen (voor administratie 7 jaar).

Delen met derden

Ik deel je gegevens niet met derden, behalve met partijen die nodig zijn om jouw aanvraag af te handelen (bijvoorbeeld de villa-eigenaar of coach in Spanje, uitsluitend als je een trip boekt).

Formulier-verwerking

Formulier-inzendingen lopen via FormSubmit (formsubmit.co), een dienst die e-mails doorstuurt naar mijn inbox. FormSubmit slaat inzendingen tijdelijk op om ze te bezorgen. Zie ook hun privacybeleid.

Website-hosting

Deze website draait op GitHub Pages. Bij een bezoek wordt je IP-adres tijdelijk door GitHub verwerkt voor het serveren van pagina's. Zie GitHub privacyverklaring. Lettertypen komen van Google Fonts.

Jouw rechten

Je hebt het recht om inzage, correctie of verwijdering van je gegevens te vragen. Stuur daarvoor een mail naar info@padelescape.nl. Ben je het oneens over hoe ik je gegevens verwerk? Dan kun je een klacht indienen bij de Autoriteit Persoonsgegevens.
